# VDPTEST — VDPコマンド終了性ストレステスト（MSX-DOSコマンド）

V9968 実機（本体内蔵VDP換装＝ポート 98h〜9Bh）で実行する負荷試験プログラムです。
疑わしいコマンドを境界条件込みで発行し、CE（および転送系は TR）ポーリングに
タイムアウトを設けて、終了しないパターンを検出します。

## 使い方

MSX-DOS 2 のプロンプトから `VDPTEST` と実行するだけです。

- 画面は Graphic 4（SCREEN 5）になり、下端に進捗バーが出ます
- テストは2パス実行されます（パスA＝表示ON、パスB＝表示OFF）
- 終了するとテキスト画面に戻り、結果を表示します
  - 全て正常終了: `SUCCESS OF ALL`
  - タイムアウトがあった場合: `TIMEOUTS: n`
  - 終了時は開始時のフォント・ネームテーブル・カラーテーブル（SCREEN 1時）と
    VDPレジスタを復帰します。レジスタは R#0〜R#7 をコンソールの保存値から、
    R#8/R#9 はテキスト画面の標準値（08h/00h）に戻します
    （RGnSAV の R#8 以降は実機では古い値のことがあるため使いません）
- 詳細はカレントディレクトリの `VDPTEST.LOG` にも書かれます
  （FAIL行にパス・ケース番号・コマンド・全パラメータ・最終 S#2 を記録）

所要時間は数分程度の見込みです（タイムアウト発生時は1件あたり最大約10秒追加）。

## テスト内容（71ケース＋特殊3種）

- HMMV / HMMM / YMMM: 全面・ページ跨ぎ・重なり・端ぴったり等
- LMMV: 全論理演算（IMP/AND/OR/XOR/NOT＋T付き）、全面、1ドット
- LMMM: 論理演算各種・重なり
- LMMC / HMMC / LMCM: CPU転送系（境界跨ぎ含む）
- LINE / PSET / POINT / SRCH（ヒット・境界まで不一致の両方向）
- 特殊: #201 実行中コマンドへの再トリガ、#202 STOP中断後の復帰、
  #203 HMMM 8×8 ＋ LMMV-TAND 8×8 を位置を変えながら2000回連続

## 検証結果（2026-11-04、3環境）

- **openMSX（素のV9958モデル）**: #59 のみ両パス FAIL、他は特殊テスト含め全PASS
- **turboR 実機（本物のV9958）**: #59 のみ両パス FAIL、他は全PASS（モデルと完全一致）
- **SX-2 ＋ V9968 Cartridge 実機**: #58 と #59 が両パス FAIL、他は全PASS

- **#59（LMCM、SX=100 から NX=200 で右端を跨ぐケース）は、本物の V9958 も
  行ごとに右端でクリップして 156ドット×100行＝15,600 ドットで完了します。**
  データブック通りの 20,000 ドットを期待した本テスト側の前提が誤りで、
  #59 の FAIL は「実チップと同じクリップ挙動であることの確認」と読んでください
  （openMSX モデル・V9968 RTL ともに実チップと一致）。
- **#58（LMCM 1×1、(255,1023)）は実チップでは PASS するため、V9968 RTL 側の
  不一致です**（NX=1 かつ NY=1 の LMCM が 0 ドット転送になる RTL の挙動で、
  修正は別途追跡中）。
